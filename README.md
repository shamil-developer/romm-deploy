# romm-deploy

Запуск официального RomM и MariaDB в Docker. Игры и данные хранятся вне Git.

## 💻 Локально

Нужны Docker с Compose, Make и OpenSSL.

1. Выполни `make up`: он создаст `.env` и остановится.
2. Создай папку игр вне репозитория и укажи абсолютный путь в `ROMM_LIBRARY_PATH`.
3. Повтори `make up`, открой http://localhost:8080 и создай администратора.

| Команда | Для чего |
| --- | --- |
| `make up` | Проверить настройки и запустить RomM |
| `make down` | Остановить контейнеры, сохранив данные |
| `make logs` | Смотреть логи |
| `make pull` | Скачать образы; затем выполни `make up` |
| `make doctor` | Проверить настройки и Docker |

Локальный `.env` содержит настройки и секреты, в Git не добавляется.
Игры клади в `ROMM_LIBRARY_PATH/roms/<платформа>/`, BIOS — в `bios/<платформа>/`.
После добавления запусти сканирование в RomM.

## 🚀 Сервер

Нужен Ubuntu/Debian с доступом по SSH и root либо `sudo` без пароля.
В GitHub: **Settings → Environments → production** добавь следующие значения.

### Variables — несекретные параметры

| Имя | Пример / назначение |
| --- | --- |
| `SSH_HOST` | IP или DNS-адрес сервера |
| `SSH_PORT` | `22` — порт SSH |
| `SSH_USER` | `deploy` — пользователь сервера |
| `SSH_KNOWN_HOSTS` | Публичный ключ сервера в формате `known_hosts`; проверяет, к какому серверу подключаемся |
| `DEPLOY_PATH` | `/opt/romm-deploy` — папка конфигурации, без пробелов |
| `ROMM_LIBRARY_PATH` | `/srv/romm-library` — папка игр на сервере |
| `ROMM_PORT` | `8080` — порт RomM на localhost сервера |
| `ROMM_VERSION` | `5.4.1` — версия образа RomM |
| `MARIADB_VERSION` | `11.4` — версия образа MariaDB |
| `DB_NAME` | `romm` — имя базы |
| `DB_USER` | `romm` — пользователь базы |

### Secrets — приватные ключи и пароли

| Имя | Что добавить |
| --- | --- |
| `SSH_PRIVATE_KEY` | Содержимое `~/.ssh/romm_deploy` — приватный ключ для входа на сервер, без парольной фразы |
| `DB_PASSWD` | Пароль пользователя базы RomM |
| `DB_ROOT_PASSWD` | Пароль администратора MariaDB |
| `ROMM_AUTH_SECRET_KEY` | Секрет для подписи токенов входа в RomM, не пароль пользователя |

Публичную часть `~/.ssh/romm_deploy.pub` добавь в настройках ВМ или в
`~/.ssh/authorized_keys` пользователя сервера. Приватный ключ туда не передавай.
Для каждого из трёх секретов RomM/базы отдельно выполни `openssl rand -hex 32`.
Сохраняй эти значения между деплоями: замена Secret сама не меняет пароль в базе.

Для `SSH_KNOWN_HOSTS` выполни `ssh-keyscan -p 22 SERVER_IP` и сверь отпечаток
с ключом в доверенной консоли сервера: `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub`.
Серверный `.env` не создаётся: параметры передаются через SSH, секретные задачи скрыты в логах.
Root и пользователи с доступом к Docker могут прочитать окружение контейнеров.

### ▶️ Ручные Action

В **Actions** выбери workflow и нажми **Run workflow**.

| Workflow | Для чего |
| --- | --- |
| 🔧 **1. Install Ansible** | Проверить и установить Ansible на сервере |
| 🐳 **2. Prepare environment** | Установить Docker/Compose и создать папки |
| 🚀 **3. Deploy RomM** | Развернуть или обновить RomM и проверить API |
| ⏯️ **4. Manage containers** | `start` — запустить, `stop` — остановить, `restart` — перезапустить |

Новый сервер: **1 → 2 → 3**. Обновление: **3**. Управление существующими контейнерами: **4**.
CI проверяет конфигурацию при push/PR; автоматического деплоя нет.

### 🔗 Открыть через SSH-туннель

```sh
ssh -N -p 22 -L 8081:127.0.0.1:8080 deploy@SERVER_IP
```

Открой http://localhost:8081, терминал с туннелем держи открытым.
Наружу нужен только SSH: порты RomM и MariaDB не публикуются на публичном интерфейсе.
Игры передаются на сервер отдельно. База, сейвы и остальные данные остаются в Docker volumes
между деплоями и остановками; не удаляй volumes, если хочешь сохранить данные.
